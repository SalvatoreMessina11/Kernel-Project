# Equal-Weight Figures

This folder contains diagnostic figures for the equal-weight benchmark.

## Files

| File | What it is | What it shows |
| --- | --- | --- |
| `equal_weight_weights_by_region.png` | Geographic exposure plot | The benchmark's regional allocation through time using the shared region palette. |
| `equal_weight_weight_heatmap.png` | Asset-weight heatmap | Daily bank-level benchmark weights, plotted on a narrow 3.5%-4.5% scale to reveal drift and rebalance effects. |
| `README.md` | Folder documentation | Describes the benchmark figure assets. |

## Usage

These diagnostics are inputs for comparison charts in later stages and help confirm that the benchmark remains close to `1/N`.
