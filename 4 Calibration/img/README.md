# Calibration Figures

This folder contains parameter diagnostics generated by `4 Calibration/calibrate.py`.

## Files

| File | What it is | What it shows |
| --- | --- | --- |
| `parameter_evolution.png` | Combined parameter overview | Broad view of selected parameters over rolling blocks. |
| `parameter_evolution_lambda.png` | Lambda path overview | Regularization-strength evolution across models. |
| `parameter_evolution_lambda_all.png` | Lambda comparison | All model lambda selections in one comparison. |
| `parameter_evolution_lambda_linear.png` | Linear lambda path | Selected ridge lambda for the linear model. |
| `parameter_evolution_lambda_polynomial.png` | Polynomial lambda path | Selected ridge lambda for the polynomial kernel model. |
| `parameter_evolution_lambda_gaussian.png` | Gaussian lambda path | Selected ridge lambda for the Gaussian/RBF model. |
| `parameter_evolution_gamma.png` | Portfolio gamma overview | Selected covariance-regularization `gamma` values. |
| `parameter_evolution_gamma_all.png` | Gamma comparison | All model MVE `gamma` selections in one comparison. |
| `parameter_evolution_gamma_linear.png` | Linear MVE gamma path | Selected covariance regularization for the linear strategy. |
| `parameter_evolution_gamma_polynomial.png` | Polynomial MVE gamma path | Selected covariance regularization for the polynomial strategy. |
| `parameter_evolution_gamma_gaussian.png` | Gaussian MVE gamma path | Selected covariance regularization for the Gaussian strategy. |
| `parameter_evolution_coef0.png` | Polynomial intercept diagnostic | Selected polynomial `coef0` values by block. |
| `parameter_evolution_gaussian_kernel_gamma.png` | Gaussian kernel width diagnostic | Selected RBF kernel gamma values by block. |
| `parameter_evolution_kernel_specific.png` | Kernel-specific parameter overview | Parameters that apply only to non-linear kernels. |
| `parameter_evolution_nonlinear.png` | Nonlinear parameter overview | Compact comparison of polynomial and Gaussian-specific selections. |
| `README.md` | Folder documentation | Describes calibration figure assets. |

## Usage

The final report copies selected calibration plots into `7 Main/img`.
