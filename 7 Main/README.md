# 7 Main

This folder contains the final report source and compiled PDF.

The main LaTeX file is `main.tex`; the compiled report is `main.pdf`. Compile from this folder so that relative paths to `img/...` resolve correctly.

The report references image files under `img`. Those assets must be present before a normal LaTeX build can complete. Delete LaTeX auxiliary files before committing, but keep `main.tex`, `main.pdf`, `img`, and any final report tables under `output`.
