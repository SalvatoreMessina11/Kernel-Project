# Kernel-Model Figures

This folder contains model-level portfolio diagnostics generated by `5 Kernel Model/kernel_model.py`.

## Files

| File | What it is | What it shows |
| --- | --- | --- |
| `linear_weight_heatmap.png` | Linear weight heatmap | Daily ticker-level allocation intensity for the linear strategy. |
| `polynomial_weight_heatmap.png` | Polynomial weight heatmap | Daily ticker-level allocation intensity for the polynomial strategy. |
| `gaussian_weight_heatmap.png` | Gaussian weight heatmap | Daily ticker-level allocation intensity for the Gaussian/RBF strategy. |
| `linear_geographic_exposure.png` | Linear regional exposure | Regional allocation over time for the linear strategy. |
| `polynomial_geographic_exposure.png` | Polynomial regional exposure | Regional allocation over time for the polynomial strategy. |
| `gaussian_geographic_exposure.png` | Gaussian regional exposure | Regional allocation over time for the Gaussian/RBF strategy. |
| `README.md` | Folder documentation | Describes kernel-model figure assets. |

## Usage

The statistics and report stages may copy selected exposure and weight diagnostics into `7 Main/img`.
