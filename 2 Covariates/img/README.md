# Covariate Figures

This folder contains diagnostic plots for the covariate set.

## Files

| File | What it is | What it shows |
| --- | --- | --- |
| `correlation_matrix.png` | Broad covariate correlation diagnostic | Pairwise relationships across the wider downloaded/engineered covariate set. |
| `model_input_correlation_matrix.png` | Model-input correlation diagnostic | Pairwise relationships among the final predictors used by the kernel models. |
| `README.md` | Folder documentation | Describes the covariate figures. |

## Usage

These plots help identify redundant features and are copied into `7 Main/img` when they are needed in the final report.
