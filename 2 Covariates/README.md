# 2 Covariates

This stage prepares the macro-financial covariates used for cross-sectional return prediction.

Expected work includes collecting rate, spread, FX, equity-index, and market variables; aligning them to the project calendar; standardising inputs without look-ahead leakage; and selecting the final modelling covariates.

Use `output` for modelling input panels and `img` for diagnostics such as correlation matrices and feature coverage charts.
