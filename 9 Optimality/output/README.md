# Optimality Output

Store the fixed-minimum maximum-weight cap search outputs here.

Expected files:

- `max_weight_grid_metrics.csv`: all evaluated caps by kernel.
- `optimal_weight_constraints_by_objective.csv`: selected cap for each kernel under Sharpe, cumulative-return, and maximum-drawdown objectives.
- `optimal_weight_constraints.csv`: Sharpe-selected caps only.
- `overall_best_weight_constraint.csv`: single best row by annualized Sharpe.
