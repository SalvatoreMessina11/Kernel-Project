# Statistics Figures

This folder contains report-ready figures generated by `6 Statistics/statistics.py`.

## Performance And Risk Figures

| File or pattern | What it is | What it shows |
| --- | --- | --- |
| `cumulative_returns.png` | Broad cumulative performance plot | Cumulative returns for the main strategy set. |
| `cumulative_returns_by_kernel.png` | Kernel comparison plot | Cumulative returns grouped by kernel strategy. |
| `cumulative_returns_all_kernels.png` | Report compact comparison | Equal-weight and all kernel strategies in one cumulative-return figure. |
| `cumulative_returns_*_vs_equal_weight.png` | Model-vs-benchmark figures | Linear, polynomial, or Gaussian cumulative returns against equal weight. |
| `drawdown_all_kernels.png` | Report compact drawdown comparison | Drawdowns for all maintained strategies. |
| `drawdown_comparison.png` | Broad drawdown plot | Drawdown paths for the strategy set. |
| `drawdown_comparison_by_kernel.png` | Kernel drawdown comparison | Drawdowns grouped by kernel strategy. |
| `drawdown_*_vs_equal_weight.png` | Model-vs-benchmark drawdowns | Linear, polynomial, or Gaussian drawdown against equal weight. |
| `rolling_returns.png` | Rolling return plot | Rolling performance by strategy. |
| `rolling_volatility.png` | Rolling volatility plot | Rolling risk by strategy. |
| `rolling_sharpe.png` | Rolling Sharpe plot | Rolling risk-adjusted performance by strategy. |

## Crisis And Exposure Figures

| File or pattern | What it is | What it shows |
| --- | --- | --- |
| `crisis_performance.png` | Crisis-period overview | Strategy behavior across selected stress windows. |
| `crisis_2008_global_financial_crisis.png` | 2008 crisis figure | Performance during the global financial crisis window. |
| `crisis_2012_euro_stress.png` | 2012 crisis figure | Performance during the euro-area stress window. |
| `crisis_2020_covid_shock.png` | 2020 crisis figure | Performance during the COVID shock window. |
| `geographic_exposure.png` | Regional exposure overview | Regional allocation by strategy. |
| `geographic_exposure_*` | Strategy-specific exposure plots | Regional allocation for equal weight, linear, polynomial, or Gaussian strategies. |

## Forecast And Allocation Diagnostics

| File or pattern | What it is | What it shows |
| --- | --- | --- |
| `oos_r2_by_block.png` | OOS R-squared overview | Forecast explanatory power by rolling block. |
| `oos_r2_by_kernel_column.png` | Model-column R-squared comparison | OOS R-squared organized by kernel model. |
| `oos_r2_*_by_block.png` | Model-specific OOS R-squared | Block-level R-squared for one kernel model. |
| `oos_r2_*_compact.png` | Report compact OOS R-squared | Compact block-level R-squared for one kernel model. |
| `oos_adjusted_r2_*` | Adjusted R-squared diagnostics | Adjusted block-level forecast performance. |
| `prediction_error_distribution*.png` | Forecast error distribution | Distribution of forecast residuals, overall or by model. |
| `prediction_error_scatter*.png` | Forecast error scatter | Realized versus predicted error behavior, overall or by model. |
| `prediction_residuals*_by_block.png` | Residual-by-block diagnostics | Residual behavior across rolling blocks. |
| `prediction_vs_realized*.png` | Prediction-vs-realized plots | Forecasts against realized returns. |
| `weight_dynamics.png` | Allocation overview | Weight changes over time across strategies. |
| `weight_heatmap_*.png` | Strategy weight heatmaps | Daily ticker-level allocations by strategy. |
| `weight_sum_*.png` and `weight_sums.png` | Full-investment checks | Daily sum of strategy weights. |
| `README.md` | Folder documentation | Explains statistics figure assets. |
